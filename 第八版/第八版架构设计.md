# 第八版架构设计：真实深度有效性 + 局部可靠性融合

## 1. 当前工程事实

- 远端 `/root/aic/v6/第六版` 使用 RT-DETR-X、三尺度 IR/Depth 编码、Tri-CSSA 融合及目标掩码辅助损失。2026-09-28 检查时训练已结束，但实例无 GPU。
- 远端最后一轮 `map50_95=0.8670` 对应全量 2000 张训练、其中 400 张又作验证，属于泄漏指标，不能说明测试集收益。
- 本地第七版的 `dfine_adapter.py` 始终返回第六版 RT-DETR；D-FINE、OQD 和 FDR 仅在设计文档中，没有实际检测器集成。第八版选择远端已跑通的 RT-DETR 工程基线。
- 第六版 HHA 数据管线把 `depth_ha`（离地高度）复制给 `depth_valid`。因此基于该值的全局质量先验不是有效深度比例，无效像素仍可能污染融合。

## 2. 论文与设计边界

1. C²Former，IEEE Transactions on Geoscience and Remote Sensing 2024，DOI `10.1109/TGRS.2024.3376819`：RGB/IR 的校准与互补建模。启发本版把统一全图质量分数扩展为逐位置可靠性分数。
2. Improving RGB-infrared object detection with cascade alignment-guided transformer，Information Fusion 2024，DOI `10.1016/j.inffus.2024.102246`：强调跨模态空间差异。本赛题输入声称已对齐，因此先加入局部可靠性控制，后续如发现残差错位再设计显式校准。

两篇论文均不是 RGB+IR+Depth 三模态赛题的直接复现。第八版模块是基于赛题深度有效掩码与已有 Tri-CSSA 构造的改进假设，性能必须用消融确认。

## 3. 模型路径

```text
RGB ── HGNetv2 ───────────── S3/S4/S5 ────────────────┐
IR ── 轻量编码器 ──────────── I3/I4/I5 ────────────────┤
Depth + valid ── 几何编码器 ─ D3/D4/D5 + valid pyramid ┤
                                                           ▼
                         ReliabilityFusion × 3 (stride 8/16/32)
                                                           │
                         Target-Aware Refiner @ stride 8/16
                                                           │
                         RT-DETR Hybrid Encoder + Decoder
                                                           │
                         12 类检测框与分数
```

对每一尺度，先把 IR/Depth 投影到 RGB 通道数。原 Tri-CSSA 的 ECA 通道分数 `s_m(c)` 保留。新增轻量 3x3 卷积从三模态均值、跨模态差异和深度有效率预测局部分数 `l_m(x,y)`。RGB/IR 的全局质量先验沿用原实现；Depth 的全局先验只表示该模态是否可用，局部有效率由掩码处理，避免 letterbox 填充被重复计入：

```text
w_m(c,x,y) = softmax_m(s_m(c) + log(q_m) + l_m(x,y) + d_m(x,y))
d_depth(x,y) = log(valid_fraction(x,y)), invalid 时硬屏蔽
d_rgb = d_ir = 0
F = RGB + tanh(scale) * spatial_attention(mixed) * projection(mixed - RGB)
```

局部卷积权重和偏置初始化为 0，`scale` 初始化为 0。全有效输入的初始计算与原 Tri-CSSA 一致；无效深度位置不进入混合特征。按像素有效比例的下采样使用面积插值，避免直接最近邻抽样漏掉局部有效信息。融合分支继续在 FP32 中运行，并保留模态编码器的反向梯度限幅。

## 4. 数据契约

- PNG 16bit 度量深度：`300 <= depth < 20000` 为有效。
- JPG 8bit 相对深度：没有物理无效值判据，原图视作有效。
- 所有深度掩码与三模态同步翻转、仿射、letterbox；填充和模态 dropout 区域为 0。
- HHA 三通道仍按原代码生成，但有效掩码独立保留，不再借用高度通道。
- 训练时先用有效掩码清除深度编码输入，再在每个融合尺度再次屏蔽无效区域。

## 5. 验证方案

使用原 `fold_0_train` 1600 张训练、`fold_0_val` 400 张验证，固定随机种子和 RT-DETR-X 权重。比较第八版 `reliability` 与 `tri_cssa` 覆盖配置，统一训练步数、输入尺寸、标注版本和推理阈值。报告总体 mAP@50-95、每类 AP、按深度有效率和 RGB 亮度分组的 AP，以及显存、延迟。全量 2000 张模型只能在选定架构后重训用于最终提交，不参与模型选择。
