## 异常与风险

1. 两个标签文件含完全重复标注行：`000013_046_00000202.txt` 与 `hehe_10_00000044.txt`。
2. 训练 RGB 至少有一对完全相同图像，但标签不完全一致。
3. 训练与测试存在少量单模态完全相同内容，这只是数据来源重叠信号，禁止据此人工推断测试标签。
4. 文件名存在明显视频/序列结构，逐帧随机划分会泄漏背景、对象和相机视角。
5. 所有训练图片至少有一个目标，真实负样本分布不足，需关注测试误报。

## 第二版处理策略

- 原始文件保持只读；运行时将 `cxcywh → xyxy → clip → cxcywh`，记录裁剪面积变化。
- 精确重复、序列组不得跨 fold；用 group-aware 多标签近似分层。
- 使用 letterbox，不把 16:9 拉伸为正方形。
- Depth 以 validity mask 区分有效、局部无效和整图缺失；JPG 深度策略必须做消融。
- EDA 脚本输出 manifest、异常 CSV、类别/尺度/中心/共现图以及 RGB/IR/Depth 质量统计。
