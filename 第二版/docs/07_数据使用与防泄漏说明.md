# 数据使用与防泄漏说明

## 允许与禁止

只使用官方训练集训练；测试集只用于最终算法推理。允许官方规则列出的公开预训练权重，但不得引入外部检测训练样本。不得根据训练测试相似帧人工生成、修正或筛选测试预测。

## 为什么随机帧划分不可靠

数据来自相机序列，文件名含序列/帧号；同一背景、对象和相机位姿的相邻帧随机分到两侧，会让验证变成近邻记忆测试。训练内部还发现精确重复 RGB 图像。第二版将明显序列前缀和重复 hash 合并为 group，整个 group 只进入一个 fold。

## 测试重叠信号如何处理

审计发现少量训练和测试 RGB/Depth 内容完全相同，但红外并不完全相同。这只能说明采集来源可能连续。该信息不得用于测试标签推断、最近邻标签复制或人工后处理；文档记录后不进入训练特征。

## 交叉验证的用途

三折用于稳定比较方案、估计方差和选择超参数。赛事禁止不同结构或阶段模型简单集成，因此最终在选定配置下训练一个模型并生成一次提交，不把多个 fold 的预测平均。

## 审计要求

每次数据版本更新都重新生成 manifest、hash 和 split 报告。若 group 解析规则变化，旧实验不可与新 split 直接比较。任何去重、clip 或异常过滤只在运行时通过配置完成，不篡改官方原始文件。
