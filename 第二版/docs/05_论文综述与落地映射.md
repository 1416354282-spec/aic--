# 论文综述与落地映射

本文只给出方法与本项目的对应关系，不宣称未实测收益。

## 1. 检测基线与定位

- Redmon et al., *You Only Look Once*, CVPR 2016：单阶段检测范式。本项目采用后续 Ultralytics YOLOv8 工程实现。
- YOLOv8 中的 Distribution Focal Loss 与 Task-Aligned Assignment：对应 `inference/decode.py` 的 DFL 解码与模型默认训练目标。重点是先保证版本和输出结构一致。
- Generalized/DIoU/CIoU、Quality Focal/Varifocal 等主题：用于分析 AP75–95 和置信度质量，但不在基线同时替换。

## 2. 多模态融合

- Cao et al., *Multimodal Object Detection by Channel Switching and Spatial Attention*, CVPR 2023：启发通道选择和空间注意力。落地顺序应是先做模态消融，再把选择/注意力放在轻量 stem 或 P3/P4/P5；不能把普通 CBAM 模块称为论文复现。
- Tang et al., *Learning Bi-Directional Fusion and Deformation-Sensitive Loss for RGB-T Tiny Object Detection*, Information Fusion 2025：与 RGB-T 小目标、高 IoU 定位高度相关。可映射到双向特征交互和定位损失实验，但当前有第三个 Depth 模态，需要重新设计并做消融。
- Zhu et al., *Collaborating Vision, Depth, and Thermal Signals for Multi-Modal Tracking*, NeurIPS 2025 Datasets and Benchmarks：虽然任务是 tracking，但三模态协同和质量门控可启发 `QualityGatedStem`。
- EvaNet（TPAMI 2026）：关注红外/可见融合质量评估，可作为动态质量分数的研究线索，不直接等价于检测融合模块。

## 3. 长尾

- Lin et al., *Focal Loss for Dense Object Detection*, ICCV 2017：降低易负样本主导。适合与标准 BCE 单独比较。
- Cui et al., *Class-Balanced Loss Based on Effective Number of Samples*, CVPR 2019：`models/losses.py` 提供有效样本数权重计算。检测中应优先用于正目标或采样，不简单放大所有负类 BCE。
- Equalization Loss、Seesaw Loss、Balanced Group Softmax：都是长尾检测/识别方向。实现成本较高，只有 Repeat Factor 和 Copy-Paste 不足时再考虑。
- Repeat Factor Sampling：按“含某类的图像频率”提高尾类曝光。已提供 sampler；它比固定手工类别表更可审计。

## 4. 增强与小目标

- Mosaic：增加尺度和上下文变化。本项目必须三模态同步、正确裁剪 box，且最后阶段关闭。
- Simple Copy-Paste：适合极少类，但三模态传感器数据中边界和 Depth 物理一致性更敏感，因此只对受控 rare crop 使用。
- 高分辨率和多尺度训练：本数据 75.9% 框面积小于 1%，比首先上复杂 Transformer 更直接。

## 5. 后处理

- Soft-NMS 可减少硬抑制，但首先必须修复 class-aware NMS。
- Multi-label candidate 保留每 anchor 多类别候选，对尾类可能有帮助；最终仍遵守每图 100 框。
- 单模型水平翻转/多尺度 TTA 需要 OOF 实证并确认赛事边界；绝不混合不同模型或不同训练阶段权重。

## 建议阅读与实现顺序

DFL/官方后处理对照 → group split → Focal/Class-Balanced/Repeat Factor → Mosaic/Copy-Paste → Channel Switching/Spatial Attention → RGB-T 双向融合 → 三模态 quality gate。论文创新必须建立在无泄漏验证和正确后处理之上。
