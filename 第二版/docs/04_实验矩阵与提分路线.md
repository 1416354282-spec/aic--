# 实验矩阵与提分路线

## 共同规范

每个实验固定 split、seed、训练预算和后处理；保存 resolved config、split hash、best epoch、mAP50/75/50–95、12 类 AP、召回、PNG/JPG 和目标尺度分桶。先在 fold 0 筛选，再在三折确认。表中收益必须由真实实验填写，不预设数字。

| 阶段 | 对照 | 变量 | 通过条件 |
|---|---|---|---|
| E00 | 第一版 | 新共享解码、class-aware NMS | 与参考后处理一致 |
| E01 | E00 | group split + letterbox + clip | 无 group/hash 泄漏 |
| E02 | E01 | 640/768/960 | 三折均值提升且显存可接受 |
| E03 | 最佳尺寸 | v8s/v8m | 提升超过折间噪声 |
| E04 | RGB | +IR、+Depth、三模态 | 辅助模态真实增益 |
| E05 | 三模态 | Depth mask、linear/log/inverse | 低质量 Depth 分桶改善 |
| E06 | 基线增强 | modal dropout 0/0.05/0.1 | 模态鲁棒性提升 |
| E07 | E06 | Mosaic on/off | 小目标 AP 提升 |
| E08 | E06 | rare Copy-Paste on/off | 尾类 AP 提升且 FP 可控 |
| E09 | E06 | Repeat Factor | 三折尾类稳定提升 |
| E10 | E06 | 正目标 class-balanced loss | 优于标准 BCE |
| E11 | 最佳训练 | NMS IoU、multi-label | OOF mAP 提升 |
| E12 | 最佳 Early | quality-gated stem | 模态消融证明有效 |

## 停止规则

- 单折提升小于折间标准差，不进入正式方案。
- tricycle 只有 25 框，单类一次跃升不能作为唯一依据。
- 同时改变两项以上时必须补做拆分消融。
- 提交分数与本地明显背离时，优先复查 split、坐标映射、decode 和提交格式，不继续盲调学习率。

## 显存档位

- ≤8GB：640，batch 4，accumulate 4，v8s。
- 12–24GB：768，batch 8，accumulate 2，v8s；可尝试 v8m。
- 40GB+：960，batch 16，v8m。即使多卡，也只输出一个最终模型。

输入尺寸升高最可能帮助占比极高的小目标，但代价近似随像素数增长；应先用短预算判断，再完整训练。
